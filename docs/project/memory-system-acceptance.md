## 日常使用

1. 新会话按当前 Agent 指令主动读取 `system://boot`；连接 MCP 不等于自动注入。
2. 未知 URI 先全文检索；使用具体实体/路径线索，不把字面匹配当向量语义理解。
3. 先看 disclosure，再解释历史片段；“在用”、访问时间或修改时间都不能替代事实核验。当前用户已提供的事实和授权优先。
4. 只写会改变未来行为的稳定结论与可回查出处；改前读旧文、先备份，再 patch/append，改后复读。当前 MCP 无 archive，本机禁删除。
5. 改完运行以下只读体检，并对实际受影响内容抽样读取；全绿不代表语义全真。

`D:/Python/python.exe -B -X utf8 backend/scripts/audit_memory.py`

## 独立冷启动结果

只给新代理读取工具，没有 Lead 报告：6 次只读 MCP 调用完成 5/5 检查。它能从 Boot 找到常用 .NET 口径，并明确拒绝把旧“在用”记录当当前线上状态或修改配置授权；搜索和叶子读取的披露警示均先于片段/正文显示。

这是一组有限场景，不是对所有模型、所有查询或所有客户端的保证。静态审查中的 URI↔edge 绑定、新旧哈希、状态保留和文档歧义已补齐；未宣称代理再次复审了修订版。
